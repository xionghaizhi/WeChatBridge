# 自定义场景

`group-close-reading.wechatflow-scene.json` 是可直接导入的“群聊精读”，不是一句“请总结”。
1.1.0 默认只给最多三条短语要点和勾选待办，不再铺长文或表格。
待办包含标题、内容、负责人和截止时间；没说清的标为待确认，不编造。
想深入时直接追问“展开排查机房异常”或“给我第2条的依据”，再针对该项补充详细说明和来源。

在微信流“设置 → 场景 → 场景管理”中导入 JSON 并启用；转发时选“群聊精读”，不要选“直接转发”。
新测试版默认每次选择，预选上次场景；只有勾选“此群以后使用这个场景，不再询问”才跳过。
可在“设置 → 场景 → 群聊匹配”中点击“恢复每次选择”。旧版 App 仍按其原来的群绑定规则执行。
也可以直接把 JSON 拖入场景列表。导入不覆盖原有内置场景，不需要重新安装 App 或额外技能。
已导入 1.0.0 的用户需要重新导入 1.1.0 才会更新提示词；仅升级 App 不会覆盖本地场景。

`keywords` 刻意留空，避免导入后凭关键词改变已有群聊匹配。请自行选择使用范围。
没有实际记录时不会编造负责人、日期和决定；这些是对模型的要求，不代表模型输出免检。

完整步骤见[测试版说明](../../docs/macos-test-release.zh-CN.md)，安全边界见[源码检查报告](../../docs/macos-source-review.zh-CN.md)。
